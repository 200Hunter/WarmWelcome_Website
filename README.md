## 📖 Overview

The WarmWelcome_Website serves as the official repository for the WarmWelcome project. This innovative solution opens a single web-page when you connect to a Wi-Fi network or hotspot. The web-page provides essential information about the network, making connections smoother and more user-friendly.

To run the WarmWelcome_Website, ensure you have the following:
